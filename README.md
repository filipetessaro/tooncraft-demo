# Tooncraft Demo

Windows demo of **Tooncraft**, anime, cartoon, painterly and comic shading for Unreal Engine 5.6 to 5.8, with no engine change and no material swap. The demo is Epic's Game Animation Sample level with the Echo character, dressed with Starter Content props near and far, packaged as a Shipping build with UE 5.8.

**Download:** [TooncraftDemo_Win64.zip](https://github.com/filipetessaro/tooncraft-demo/releases/latest/download/TooncraftDemo_Win64.zip).
Windows 64-bit, DirectX 12. No engine needed.

Unzip it anywhere and run `TooncraftDemo.exe`. You start in the Cartoon style.

| Key | What it does |
|---|---|
| WASD + mouse | Move and look (the Game Animation Sample controls) |
| 1 | Anime Cel |
| 2 | Cartoon |
| 3 | Painterly |
| 4 | Retro Comic |
| 0 | Tooncraft off |
| N | Day and night |
| M | The player in the secondary style (Anime Cel), the world keeps its own |
| H | Hide the help text |

The two spheres by the player show the per material control: the blue one is left out of Tooncraft, the orange one asks for the secondary style.

Documentation: https://apps.tessaroapps.com/tooncraft/docs/
Support: contato@tessaroapps.com

The level, the Echo character and the props are Epic Games sample content (Game Animation Sample, Starter Content).
